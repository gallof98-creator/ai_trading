# API

The complete, always-current reference with request and response schemas is generated by the
server: **http://localhost:8000/docs** (OpenAPI at `/openapi.json`). This page is an overview.

Authentication: `POST /api/auth/login` returns a bearer token and sets an httpOnly session cookie.
Cookie-authenticated writes must send an `X-Requested-With` header. Roles: viewer < trader < admin.

| Group | Endpoints | Minimum role |
|---|---|---|
| Auth | `POST /api/auth/login`, `POST /api/auth/logout`, `GET /api/auth/me`, `POST /api/auth/users` | – / user / user / admin |
| Settings | `GET/PUT /api/settings`, `GET /api/audit` | viewer / admin / admin |
| Brokers | `GET/POST /api/brokers`, `PUT /api/brokers/{id}/credentials`, `POST /api/brokers/{id}/connect|disconnect`, `GET /api/brokers/status` | viewer / admin |
| Paper | `POST /api/paper/accounts`, `POST /api/paper/accounts/{id}/reset`, `POST /api/paper/replay` | admin / admin / trader |
| Portfolio | `GET /api/overview`, `GET /api/portfolio/equity`, `GET /api/trades`, `GET /api/instruments`, `GET /api/markets`, `POST /api/instruments`, `DELETE /api/instruments/{id}` | viewer / trader |
| Strategies | `GET /api/strategies`, `GET/POST /api/deployments`, `PATCH/DELETE /api/deployments/{id}`, `GET /api/deployments/{id}/history` | viewer / trader |
| Execution | `GET /api/orders`, `GET /api/fills`, `GET /api/signals`, `GET /api/approvals`, `POST /api/approvals/{id}`, `POST /api/feed/tick` | viewer / trader |
| Risk | `GET /api/risk`, `POST /api/risk/kill-switch` (engage: trader, release: admin), `POST /api/risk/breakers/{name}/reset` | viewer / trader / admin |
| Notifications, FX | `GET /api/notifications`, `POST /api/notifications/read-all`, `GET/POST /api/fx`, `POST /api/fx/refresh-ecb` | viewer / admin |
| Market data | `GET /api/market/coverage|analysis|quality`, `POST /api/market/import-csv`, `POST /api/market/import-csv-bulk`, `POST /api/market/generate-simulated` | viewer / trader |
| Data provider | `GET /api/market/providers`, `PUT/DELETE /api/market/providers/{name}/key` (admin), `POST /api/market/providers/{name}/test`, `POST /api/market/providers/{name}/symbols`, `POST/GET /api/market/download`, `POST /api/market/download/cancel`, `GET /api/instruments/stats` | viewer / trader |
| Global Markets | `GET /api/global/coverage`, `GET /api/global/providers`, `GET /api/global/securities`, `GET /api/global/securities/{id}`, `POST/GET /api/global/sync`, `POST /api/global/sync/cancel`, `POST /api/global/securities/activate` | viewer / trader |
| Scanner | `GET /api/scanner/fields`, `POST /api/scanner/run`, `POST/GET /api/scanner/metrics`, `GET/POST /api/scanner/saved`, `DELETE /api/scanner/saved/{id}`, `GET/PUT /api/scanner/watchlists`, `DELETE /api/scanner/watchlists/{id}` | viewer / trader |
| Global analysis | `GET /api/global/overview`, `GET /api/global/ranking-models`, `GET /api/global/rankings`, `POST /api/global/report` | viewer / trader |
| Global strategies | `GET /api/global/strategies/options`, `POST /api/global/strategies/backtest`, `GET /api/global/strategies/tests`, `POST /api/global/portfolio/target`, `POST/GET /api/global/portfolio/proposals`, `POST /api/global/portfolio/proposals/{id}/execute`, `GET /api/global/portfolio/holdings`, `POST /api/global/portfolio/settle` | viewer / trader |
| Backtesting | `POST/GET /api/backtests`, `GET /api/backtests/{id}`, `POST /api/backtests/walk-forward`, `POST /api/backtests/compare`, `POST /api/backtests/scan` | trader / viewer |
| Quant AI | `GET /api/ai/regime`, `GET /api/ai/anomalies`, `POST /api/ai/models/train`, `GET /api/ai/models`, `GET /api/ai/models/{id}/drift`, `POST/GET /api/ai/reports`, `POST/GET /api/ai/proposals`, `POST /api/ai/proposals/{id}/apply` (admin), `POST /api/ai/proposals/{id}/dismiss` | viewer / trader |
| System | `GET /health` | – |

Errors use standard status codes with a `detail` message: 400 (refused, with the reason), 401, 403,
404, 409 (state conflict), 422 (validation), 429 (rate limit).
